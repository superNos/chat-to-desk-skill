# 工作台验收

验收只写在这里。按这次交付的范围选条目：只交付工作梳理或草案时查第 1 到 3 条；交付可操作的工作台时全部查；局部调整只查受影响的条目。一次已授权的真实试用可以同时验证多条。发现缺口时记下具体动作、看到的状态和缺少的能力，查完即停，不为换配色或改文案重跑全部检查。

1. **依据和筛选**。说清授权范围、实际读过多少、缺了哪些。同一交付目标跨日、跨对话已合并。当前工作台只放还要处理的事，可以为空；问完即止的咨询和已办完的事不在里面。常用按钮有跨事项复用或用户明确以后还会用的依据，同一件事改二十轮也只算一次。
2. **页面元素有来处**。每个区域、按钮、字段和状态都能指回用户确认过的工作，用他的叫法。没有依据的想法只在“待确认建议”里。没有用户要求、约定或执行依赖的拦截和提醒已去掉。
3. **授权和保存**。分析历史、保存规则、交给 Agent 执行三项授权分开。未经同意，分析发现不落盘。工作模型和说明里没有凭据、证件、付款信息、第三方敏感资料和大段原文。页面、配置和数据在用户指定的本机目录，与 skill 分开。
4. **首屏简洁且适合面板**。在总对话旁的实际面板宽度下，能先看见工作对象、下一步和最新结论；布局对应比较、阅读、修订等实际操作，没有把后台步骤照搬成向导或大表单。对照数据用表格，依据、过程、历次执行默认折叠。页面上没有能力核实表、欢迎语或装饰性数字；真实列表为空时不混入演示记录。核心控件来自所选组件库，长文本、窄屏和键盘操作可用。
5. **从面板走完一件真实工作**。确认面板实际在总对话中展示；点一个已授权的对象操作，真实目标收到工作，进度和结论自动回到这件事和这一轮，关掉再打开仍能找回。总对话协调、执行对话处理，面板没有另建聊天中心。未接通的动作禁用，服务端也拒绝。只打开了外部浏览器或仅验证通信时如实说明；外部动作由用户本人完成。
6. **并行和排队**。两件事同时发起，交给不同对话的同时进行；交给同一对话的显示“排队中”，前一轮结束后自动开始。原对话正忙时，工作排进它自己的队列，结果仍回到这一轮。整个过程中用户正在看的 Codex 页面没有被打开或切换。
7. **去向和项目**。固定在原对话办的事回到原对话；每件事各开对话的，同一件事的继续和重试回到同一个对话。新建的对话在用户平时办这类事的项目里，项目不符时没有发送。
8. **使用说明**。用户能从说明里知道能做什么、怎么打开、哪些事由他本人完成、还有哪些待确认建议。

只在相关流程核对：

- **在总对话中指代当前对象**：在正常试用中选中一件事及结果版本，再说“核对这一项”，确认总对话读取了实际选择；发送后切换选择不会改变原任务归属。无选择或读取连接缺失时不猜对象，不要求用户复制完整提示词。通过已有业务入口执行并读回结果，不重复创建执行记录。
- **只读联网和指定事项查询**：在实际执行的那一轮以只读权限从授权来源取回详情；能区分没有权限、连不上、查不到和多条匹配。
- **连接或凭据失效**：处理入口放在对应事项旁；凭据通过本机安全方式更新，不进入结果和记录。
