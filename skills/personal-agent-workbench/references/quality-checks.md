# 工作台验收

按这次交付的范围选检查项。同一条已授权的试用记录可以同时验证执行、回传、排版和找回结果。检查发现缺口时，记录具体动作、已观察到的状态和缺少的能力。

| 这次交付什么 | 查到哪里 |
| --- | --- |
| 工作模型或设计草案 | 检查工作依据、授权与草案。尚未搭建的能力标为待核实。 |
| 首个可操作的工作台 | 对照已确认草案检查页面，走完一次真实工作，再查涉及的宿主能力。 |
| 局部调整 | 从改动的功能及其直接影响开始。排版调整用已有记录；发送或回传调整核对对应目标与轮次。只测过通信时，结论限于通信。 |

## 工作依据与草案

- [ ] 说明了授权范围、实际覆盖和缺失来源。跨日、跨对话的同一交付目标已归并；工作日期来自证据，空白日期不会产生待办。
- [ ] 每个功能和元素都对应用户已确认、修正或限定的工作，使用用户自己的叫法。线索、否定项与未答复的推测没有进入页面。缺少依据的想法留在待确认建议里。
- [ ] 用历史中的零散咨询和已交付事项检查筛选。当前列表只含范围内尚需处理的工作，可以为空。草稿完成、交付完成、暂停与状态未知按用户的交付终点判断。已完成的结果按原授权可查，平台对话和记录仍保留。
- [ ] 常用功能有跨独立事项复用的证据，或有用户明确的未来复用意愿。同一事项即使改了二十轮也只算一次。一次明确安排可以单独发起。
- [ ] 选一项工作，从证据讲到触发条件、必要输入、步骤、人工决定和产物。对照过去成功的做法，去掉缺少依据的拦截和提醒；多步骤中的依赖能从真实工作解释。
- [ ] 草案能让用户说出要办哪件事、怎样开始和去哪里看结果。首版范围与证据相称，协作技能解决了具体的规划或设计问题。分区、字段、状态及现成工具的选择都能从这位用户的工作解释。

## 授权与保存

- [ ] 遵守已约定的读取顺序、排除项和保存期限。授权待定的部分保留待定；对承诺稍后询问的事项，按约定处理。
- [ ] 分清历史分析、规则保存和材料交给 Agent 的授权。分析发现未经同意不落盘；长期规则及固定背景未经同意只留编号和“待问”。运行时只交出获准的材料，包括自动带入的背景。
- [ ] 工作模型与说明只保留必要概括及引用，排除凭据、证件、付款信息、第三方敏感资料及大段对话原文。页面、说明、配置和用户数据位于指定的本机目录，独立于 skill。
- [ ] 用户清楚哪些材料会交出、去往哪个目标。对外发送、提交、推送、付款、发布、删除等操作均有针对本次的明确同意；已明确的同一动作不重复确认。

## 可操作的页面

- [ ] 运行页面与用户确认的草案一致。用户能一眼找到工作对象、当前状态、主要动作和最新结论。需要改变已确认的做法时，先和用户核实。
- [ ] 新建或整体改版已使用成熟组件库或宿主设计系统。核对选择依据、版本、依赖、源码引用与实际核心控件；列表、输入、按钮和状态反馈使用一致的主题和尺寸。
- [ ] 用一条真实结果核对呈现。结论和影响判断的限制先显示；可比数据按列对齐，标题、单位或日期口径与原结果一致；依据可展开。顺手看长文本、窄屏和键盘操作。
- [ ] 工作台在本机打开，组件和字体等资源在本机加载。采用附带服务时，按运行指南执行 `workbench.py check`；采用等效做法时，说明本机限制与用户选定的方案。
- [ ] 使用说明覆盖[设计指南第 6 节](workbench-design.md)列出的内容，写清下次怎样打开。用用户熟悉的词解释操作，只采用用户提供的称呼。

## 从页面走完一件真实工作

- [ ] 从首屏发起一项已授权的业务操作，核对真实目标收到的工作内容。成熟流程只选择对象和本次参数即可执行；没有复用依据时验证已确认的一次工作。未接通的动作在页面禁用，服务端也拒绝发送或创建执行记录。
- [ ] 进度和结论自动回到本次事项与轮次，关闭再打开仍能找回。新一轮有独立结果。对照真实回执区分已排队、已开始与已完成；连接中断时显示最后证据，按原轮次恢复。
- [ ] 分开核对业务步骤与 Agent 执行状态。上一步的真实产物支持下一步才推进；失败或不确定时指出停在哪一步。已完成的外部动作不会因重试被再次执行。
- [ ] 有临时安排时，当前列表为空也能发起；补充要求能指向已有事项或指定版本的结果。重试沿原事项单独记录，新事项独立，摘要指向实际最新一轮。

## 只在相关流程核对

- **绑定项目或固定对话**。用宿主返回的标识核对用户平时办理该工作的项目和原对话。项目即使共用目录仍可区分；新建、续办和重试沿用对应归属。目标失效或归属不符时停止发送。历史迁移只处理用户指定的范围。
- **只读联网与编号查询**。在实际执行环境、以本轮只读权限从授权来源取回详情。用默认列表外的事项核对完整编号、所属范围及来源内部标识。结论回到原事项；能区分无权限、不可达、无匹配和多条匹配。异常分支可用隔离样例验证。
- **连接或凭据失效**。展示具体处理入口；连接验证与业务结果分开。凭据通过本机安全方式更新，失败时保留有效配置，结果中不含凭据。
