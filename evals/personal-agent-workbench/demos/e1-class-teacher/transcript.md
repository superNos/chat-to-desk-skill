# 逐轮对话记录（e1-class-teacher）

本文件由演示脚本从会话事件中机械提取，未做改写：

- “本轮开始时工作目录里的文件”由脚本在每轮开始前列出，表示 Agent 在本轮能看到的全部场景材料；
- “演示人输入”是每轮发给 Agent 的原文；
- “Agent 回复”是该轮最后一条消息原文；
- “Agent 读写的文件”是该轮 Agent 自己执行的命令首行（超过 170 字截断）和写文件操作。会话事件不记录文件改名，改名可对照相邻两轮开始时的文件列表看出。

临时工作目录替换为 `<演示目录>`，临时配置目录替换为 `<演示配置目录>`，技能文件位于 `<演示配置目录>/skills/personal-agent-workbench/`。

**结论**

**一、家长沟通记录（按学生整理）**
- 这一项对应你说的“按学生找以前的沟通最麻烦”，也对应“常常同时有好几条没回”。
- 这是一份放在你电脑上的文档，每个学生单独一节。每收到一条家长消息，就在这个学生名下记一笔：日期、家长消息的摘要、回复的要点，以及草稿在哪个对话里。
- 文档最上面有一个“还没回的”清单，你一眼就能看到哪几条在等你。
- 每条消息只记四种情况：还没回；交接内容已备好，等你自己粘贴；草稿已拿回，等你改完自己发；你已发出。“你已发出”只在你告诉我之后才标，我不会自己推断。
- 学生只写编号，比如 S07。记录里不写学生全名、家长电话，也不写成绩或身体情况的细节。

**二、起草家长回复用的交接内容**
- 这一项对应你平时的做法：把家长消息交给 Agent 起草，你改完自己发。
- 我现在没法确认能不能直接替你新开对话、把内容送进去，也没法确认能不能把结果取回来。所以这一步还是由你复制粘贴，每次都写明“需手动完成”。
- 按你说的范围，交接内容里只放家长消息的摘要，不放学生全名、家长电话，也不放学生编号。比如：

```text
【这次要做】起草一条给家长的回复
【家长消息摘要】家长觉得最近作业量偏多，问能否调整
【要求】只起草，我自己改、自己发
【完成后给我】一条可以直接修改的回复草稿
```

- 有一点要说明：Agent 只看到摘要，起出来的草稿可能需要你多改几句。

**三、周五班级通知的开场说明**
- 这一项对应“学期中每周五要重新讲格式”。
- 长期记下格式这件事你说不清，所以我不把它存进文件，只在这里给你一段文字，你自己留着，写通知时贴在开头：

```text
请帮我写本周五的班级通知，按这个顺序：先写安全提醒，再写作业，最后写下周活动。
```

- 等试用结束回顾时，我再问你要不要长期记下来。

**每次都由你自己做的事**
给家长发回复、在班级群发通知，都由你自己发。我和工作台都不会替你发。

**暂时不放进来的**
- 语气方面的固定要求：你说不清，先不加。
- 网页、统计、提醒之类：没有依据，先不加。

**请你定这几件事**
1. 这三样东西可以吗？有没有想删掉或改的？
2. 交接内容按“只放家长消息摘要”来做，可以吗？周五通知里的作业和活动内容，是你自己填，还是也可以由我放进交接内容？
3. 家长沟通记录存在你电脑的 `output/` 文件夹里，可以吗？里面会有家长消息的摘要，学生只用编号。
4. 先试用多久？拿不准的话，我建议先试两周。
