## 第 4 轮：确认 → 草案

### 本轮开始时工作目录里的文件

- `output/工作梳理.md`
- `platform/README.md`
- `platform/conversations.json`

### 演示人输入

```text
【用户说】
确认。请给我看草案。
```

### Agent 回复

我建议先在 `output/` 搭一个本机工作台。打开浏览器后，先看到**还没回的家长消息**，然后可以**按学生找以前的沟通**。周五通知放在单独一处。

**家长消息。** 收到新消息时，你用一个只在本机使用的学生代号记下这件事，再写一段摘要。几条消息可以同时留在“还没回”里。要请 Agent 起草时，你先看到这次要交的内容，确认后再复制到新对话。要补充情况或修改某一版回复，就从那条消息生成交接文字，粘贴回原对话。Agent 给出的草稿或改稿可以贴回同一条记录。

**按学生找以前的沟通。** 输入学生代号，就能按日期看到该学生的家长消息摘要和你带回的回复。学生代号只用于本机查找。交给 Agent 的材料只包含你确认过的家长消息摘要和本次写作要求，摘要里不能有学生全名或家长电话。

**周五班级通知。** 学期中的周五，你可以新开一份通知，填本周要说的事项和这次想用的顺序，之后把稿子贴回来继续改。固定格式是否长期保存还没定，所以每次由你填写。若要请 Agent 处理通知，需要另行确认这次可以交哪些材料。

目前只核实了历史读取。新开对话、继续原对话和取回结果都靠你手动复制粘贴。工作台会在交接准备好时显示“需手动完成”，在你点“已粘贴”后显示“已交给 Agent”。看不到后续就显示“最新情况未知”，贴回草稿后显示“草稿已取回，待你确认”。给家长发消息或发布通知是单独的一步，每次由你决定，实际发出后才记为已发。

我建议首版先试**家长消息和按学生查找**，因为这是每周都遇到、也最难找回的一块。周五通知先保留在草案里。如果你同意按这个范围在 `output/` 搭第一版，回“确认”即可。
