# 家长沟通工作台 · 首版

## 结论

先集中处理还没回的家长消息，并按学生查找过往沟通。每周有十几条家长消息，常有几条同时没回，按学生找之前的沟通尤其费时。

## 页面上有什么

| 页面内容 | 用法 | 依据 |
| --- | --- | --- |
| 还没回的家长消息、记一条新消息 | 用学生代号和摘要记下消息。只有你确认已经回复家长后，该条才会移出此处 | W1（已确认） |
| 起草、补充、按版本修改、带回草稿 | 在同一条消息下整理交接和稿件。原对话位置可另记在本机，方便再次打开 | W1、W2（已确认），首版草案已确认 |
| 按学生查找 | 输入完整学生代号，按日期查阅本机的消息摘要、草稿和你记下的实际回复 | W2（已确认） |
| 状态和依据 | 看每条消息交到哪一步，以及状态根据什么来显示 | W1（已确认），首版草案已确认 |

## 输入去哪里

学生代号、原对话位置和实际回复只记在本机。每次生成交接前，请确认可以交给 Agent 的家长消息摘要和本次写作要求，两处都要去掉学生全名、家长电话及其他个人信息。页面会提示疑似电话号码，姓名等内容仍需你检查。起草去新对话，补充和修改回原对话。修改时选定具体稿件版本，再填写要求。

## 结果回到哪里

把 Agent 草稿贴回原消息下对应的交接位置，页面会标明来源并保留版本。实际发给家长的话可以在你确认发送后另记一笔。只录入已去掉个人信息的文字。

## 状态怎么显示

备好交接时显示“需手动完成”。你确认已粘贴后显示“已发送（最新情况未知）”，这里指已交给 Agent。贴回草稿后显示“待确认”。明确报错时才记为“失败”。是否已发给家长另行记录。

## 每次都要你确认的动作

每次生成交接前，由你确认这份摘要和写作要求可以交给 Agent。给家长发送由你本人完成，实际发出后才在工作台记为已发。

## 怎么打开

用 Python 3 执行下面的命令。浏览器通常会自动打开，也可以在浏览器输入命令打印的本机地址。关闭进程后，下次用同一条命令打开。记录存于工作台目录的 data/。

```sh
python3 <演示配置目录>/skills/personal-agent-workbench/scripts/workbench.py serve --dir <演示目录>/output --open
```
