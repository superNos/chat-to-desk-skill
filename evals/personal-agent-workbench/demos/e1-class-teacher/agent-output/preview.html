家长回复交接

只复制家长消息摘要和起草要求，学生代号留在本机。新开、继续、取回都需手动完成。

收到新消息 → 新对话
例如复制“家长想知道手工课要带几张纸。请起草一条回复供我修改。”粘贴发送后，在学生名下记对话日期和标题。
家长补充情况 → 同一条消息的原对话
按文档中的标题找回原对话，贴入新增的摘要，请 Agent 结合补充情况再起草。
想改草稿 → 原对话里的指定版本
例如回到《图书角收书》，写“请把上一版缩短成一句话，给我修改后的草稿。”
取回结果 → 同一学生、同一条消息
手动把要点记为“草稿”。你本人确认并发给家长后，再记“实发”要点。若仅确认已粘贴，之后的进展写“最新情况未知”。

周五班级通知

学期中每周五，开场说明从当前对话取用。本周素材由谁填写待定，暂留空。终稿留在写这份通知的地方，由你本人审阅、确认并发布。

实际填写请打开同一文件夹里的《家长沟通记录》。三段可复制的写法在《家长回复交接》。
