## 按学生找以前的沟通

在文档里搜索学生编号。第一次记录时，把下面的小节复制一份，将标题换成学生编号。以后有新消息，就在同一小节添一行。同一天有几条，用日期和所问的事一起区分。

### 〔学生编号〕

| 日期 | 家长消息摘要 | 回复到哪一步 | 草稿在哪个对话（日期、标题） | 回复要点 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

新收到时填“还没回”。准备好交接文字后填“等我粘贴”。粘贴后可在这一格注明“已贴到对话，最新情况未知”。取回草稿后填“草稿已拿回，等我改发”，在要点前写“草稿”。自己确认并发出后填“我已发出”，按实际发出的那版写“实发”要点。这样下次能查到你当时怎样回复。

本机只记必要摘要和要点。学生用编号，略去真实姓名、联系方式和个人敏感细节。给 Agent 起草时，另用《家长回复交接》，学生编号和本地记录留在这里。
