# 家长回复交接

先在《家长沟通记录》找到这条消息。按下面的去向选一段，只复制框内文字。方括号里填写家长消息的必要摘要，略去原话、姓名、电话、学生编号和能认出个人的细节。

**新收到一条消息**　需手动完成。开一个新对话，粘贴下面这段，再把对话日期和标题记回这条消息旁。

```text
请根据这段家长消息摘要起草回复。
家长消息摘要：[用一两句概括家长问的事]
请给我一条可修改的回复草稿，我来改、我来发。
```

**家长补充了情况**　需手动完成。按记录里的日期和标题找到原对话，把下面这段贴回去。

```text
请接着这个对话里的同一条家长消息处理。
补充的家长消息摘要：[只写新补充的意思]
请结合补充情况给我一版回复草稿，由我审阅后发送。
```

**想改已有草稿**　需手动完成。回到原对话，定位要改的那一版。若是较早的一版，把“上一版”改成它在该对话里的位置。

```text
请修改本对话中上一版回复草稿。
这次想改的是：[只写修改要求]
请给我改后的整条回复，供我审阅。
```

草稿在相应对话里。读过后，把回复要点手动记回同一学生、同一条消息旁，标为“草稿”。实际发给家长后，再记实发要点。
