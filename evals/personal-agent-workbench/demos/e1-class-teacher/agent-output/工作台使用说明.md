打开《家长沟通记录》，顶部看还有哪些家长没回，往下按学生编号找以前的沟通。两份可以直接编辑或复制的本地文档，加上当前对话里的周五通知开场说明，就能开始试用。

## 输入去哪里

新消息的摘要贴到新对话。补充摘要和改稿要求贴回记录中对应的原对话。如果同一学生有几条消息，先核对日期、问题和草稿版本。《家长回复交接》给出了三种可复制写法。只交出家长消息摘要和必要的起草要求。

学期中周五，可以在当前对话找到开场说明，自行留用。本周作业和活动由谁填写待定，试用时留空，不生成含通知素材的交接内容。

## 结果回到哪里

回复草稿留在产生它的对话里。你手动把要点带回该学生对应的那一行，并注明草稿或实发。以后查“当时怎么回的”就看实发要点。周五通知如由你自行起草或修改，终稿由你在写那份通知的地方审阅、取用。

## 怎样看进展

“还没回的”一直列到你确认已回复家长。准备好交接文字显示“等我粘贴”；你确认已粘贴发送后才记“已贴到对话”。只有看到本次处理的实际回复才知道 Agent 已开始，看到完整草稿才算起草完成。手动取回后标“草稿已拿回，等我改发”。拿不到最新情况就保留最后能确认的一步并注明“最新情况未知”。只有出现明确报错时才记失败原因。

## 每次由你确认

你审阅并亲自发送每条家长回复、发布每份班级通知。你确认已经发给家长后才记“我已发出”。
