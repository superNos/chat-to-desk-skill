## 哪些先放下

- 座位投诉（H4）只有一次语气要求，是否通用说不清，因此没有固定回复口吻。个人旅行（H10）由你明确排除。
- 班级群、私聊、平时怎样找通知，以及对话以外的班务都说不清，暂缓按渠道整理和增设班务入口。
- 同时有几条没回，支持一张清单。对话和你的反馈都没有提出按轻重排序、设到期提醒或统计消息量的需要。
- 手动交接足以开始试用。演示平台只核实了读取历史，其余三项待核实，所以没有自动派发、自动取回或代发按钮。

## 回顾

两周后先听你说哪些用上了、哪一条还需要翻旧对话。若需要读新的对话或试用记录，会先确认范围。调整由你决定。
