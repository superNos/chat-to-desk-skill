## 把查询交给 Agent

先在本机选好去向，再填下表右栏的空白。只复制填好的查询说明。口径按需带上，查询思路用自己的话概括，同事代号、原始数据、结果数值和附件留在交接内容之外。每次由你核对并手动发送。

| 在哪里发 | 可以复制的查询说明 |
| --- | --- |
| 新问题 → 新开查询对话 | 这次用的指标口径是〔　〕。请按〔查询思路〕梳理计算步骤，给我可核对的查询思路。 |
| 加条件 → 本行原查询对话 | 接着上次查询，请把〔新增筛选思路〕纳入计算，给我更新后的步骤。 |
| 改结果 → 本行原对话中选定的那次回复 | 请调整这次回复中的〔待改的查询思路〕，按〔修正思路〕给我改后的步骤。 |

## 看结果，记答复

自动取回结果待核实。请打开本行的查询对话，亲自核对结果，再把回复位置记回本行。修改后可追加新版回复的位置，只记位置和进展。若有多个相似查询，发送前先核对日期和原回复。

交接文字备好时写“需手动完成”，确认送达后写“已发送”。看到开始处理的证据才写“已开始”，看到所需结果才写“已完成”。明确报错才写“失败”。看不到后续时，保留上次状态并注明“最新情况未知”。

答复准备好后写“答复已备好，待你转发”。由你本人确认内容并转发给同事，随后才记“已转发”。
