它是怎么工作的

你自己的 Agent 按这六步和你一起做出一个只属于你的工作台。每一步结束都先给你看，你同意了才往下走；随时可以停下或退回上一步。

1确认范围你决定

看哪些对话、看多久以内的、跳过哪些主题，整理出的内容存不存、存在哪里。

授权① 同意分析历史，才开始读
2理解工作Agent 整理

只在你同意的范围里读。找出你反复交代的背景、隔天还要接着做的事、事后找不回的结果，每一条都写明出自哪段对话。

3和你校准你判断

Agent 用你的话讲出发现，你逐条说对、不对，或只在某些情况下成立，再补上对话里看不到的事。

授权② 想长期记住你的做法（如固定格式）时，单独问你
6持续调整你确认

按实际使用增加、修改或去掉内容。Agent 记住的每条规则，你都可以保留、修改、限定范围或删除。

5搭建并试用你选范围

Agent 在你电脑上搭一个用浏览器打开的工作台，先只放你最在意的一到三件事。交给你之前，先在页面上试一遍：交代一件事、看到状态、拿回结果。

授权③ 要把材料交给 Agent 或别的对话处理时，单独问你
4设计工作台Agent 起草

只用你确认过的内容。草案里每个输入框、记录、状态都写明来自哪件事。工作很零散时，只做一个最小的：一个交代事情的入口，加一处找回结果的地方。

每次都由你本人确认：发送消息或邮件、提交、付款、发布、删除。以前确认过、Agent 记住了你的习惯，都不能代替这一次的确认。
平台做不到的事，不假装做到：没核实过能直接交给 Agent 时，工作台给你一段可复制的文字，标明“需手动完成”；结果由你粘贴回工作台里原来的位置。

虚线框是需要你单独授权的地方；②和③到需要时才问。三项授权互不代替。
